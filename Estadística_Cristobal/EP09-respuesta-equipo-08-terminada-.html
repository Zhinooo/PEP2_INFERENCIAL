  1. Homocedasticidad (Varianza Constante de los Residuos)

Se evalúa la hipótesis nula de varianza constante mediante la prueba de Breusch-Pagan / Score Test.

Al obtener un p-valor mayor a 0.05, no se rechaza la hipótesis nula de homocedasticidad, concluyendo que la varianza de los residuos se mantiene constante.

pred_rls <- predict(modelo, newdata = muestra_test)
pred_rlm <- predict(modelo_multiple, newdata = muestra_test)
pred_rlm_corregido <- predict(modelo_multiple_corregido, newdata = muestra_test)

# Función para calcular las métricas de evaluación externa
metricas_prediccion <- function(observado, predicho) {
  rmse <- sqrt(mean((observado - predicho)^2))
  mae <- mean(abs(observado - predicho))
  r2_predictivo <- 1 - sum((observado - predicho)^2) /
    sum((observado - mean(observado))^2)

  data.frame(
    RMSE = rmse,
    MAE = mae,
    R2_predictivo = r2_predictivo
  )
}

# Cálculo y comparación de las métricas de los tres modelos
resultados_prediccion <- bind_rows(
  cbind(Modelo = "RLS", metricas_prediccion(muestra_test$Weight, pred_rls)),
  cbind(Modelo = "RLM original", metricas_prediccion(muestra_test$Weight, pred_rlm)),
  cbind(Modelo = "RLM corregido", metricas_prediccion(muestra_test$Weight, pred_rlm_corregido))
)
